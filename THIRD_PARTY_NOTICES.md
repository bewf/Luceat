# Third party notices

Luceat includes these fonts. Each one is under the SIL Open Font License 1.1. The full licence text for each font is in the jar as `assets/luceat/font/OFL-*.txt` and in this repository under `26.1.2/src/client/resources/assets/luceat/font`.

- Bricolage Grotesque: menu text and headings
- Instrument Serif (italic): preset quotes
- Huninn: Balanced preset name
- Jersey 25: Potato preset name
- Birthstone: Phenomenal preset name
- UnifrakturMaguntia: Hardcore preset name

The copyright line for each font is the first line of its `OFL-*.txt` file. Bricolage Grotesque, Huninn, Jersey 25, Birthstone and Instrument Serif are Latin subsets of the originals. UnifrakturMaguntia is unmodified, because its licence reserves the font name.
